Write a self-contained TypeScript module `helpers.ts` (no imports, no external
dependencies) with two exported functions:

1. A function that clamps a number into an inclusive range, given the value,
   the lower bound and the upper bound.
2. A function that title-cases a sentence: every whitespace-separated word gets
   an upper-case first character and lower-case remainder.

The module must type-check under `strict` with `noUncheckedIndexedAccess`.

Return only the contents of `helpers.ts` in a single TypeScript code block.
